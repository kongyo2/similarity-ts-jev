Conventions of these repositories that a reviewer knows: in zod, every file under src/v4/locales is a self-contained translation contributed separately and locale files are deliberately not shared with one another, and src/v3 is a frozen previous major version kept apart from src/v4. In es-toolkit, src/compat re-implements lodash-compatible variants and a compat function whose semantics differ from the main one stays separate, while a compat function that is byte-for-byte the main function is expected to re-export it. In date-fns, every public function is its own module with its own Options interface, and the parse/_lib/parsers classes are expected to share code through their base class. In remeda, every function is its own module and mirror-image type machinery (find/findLast, startsWith/endsWith) is accepted as is. Test files are never refactored for duplication.
